# Glamborrow

Glamborrow is a rental e‑commerce web application with a customer checkout flow, cart management, and an admin dashboard for internal management.

## 🚀 Features
- Customer‑facing frontend (browse items, add to cart, checkout)
- Secure checkout integrated with PayFast
- Admin dashboard for managing rentals and orders
- Node.js + Express backend with MongoDB
- Responsive UI built with HTML, CSS, and JavaScript
